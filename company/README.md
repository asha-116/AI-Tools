# company/ — the company's memory

| Folder            | Contents                                  | Who writes                 | Rules                            |
| ----------------- | ----------------------------------------- | -------------------------- | -------------------------------- |
| `goals.md`        | weekly/monthly goals                      | owner                      | ≤ 5 bullets per horizon          |
| `policies/`       | refund, pricing, brand voice, disclaimers | owner approves             | changes need `approved-by-owner` |
| `knowledge-base/` | support answers                           | Support agent (PR) + owner | no customer data                 |
| `memory/`         | agent learnings                           | agents                     | append-only; summarised monthly  |
| `ledger/`         | sales, refunds, settlements, costs (CSV)  | Controller                 | IDs + amounts only, no PII       |
| `reports/`        | daily, weekly, agent logs                 | agents                     | no secrets, no PII               |
| `social-queue/`   | social post drafts                        | Social agent               | never auto-posted                |
